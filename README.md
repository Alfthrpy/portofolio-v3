# portofolio-v3

Personal portfolio of **Muhammad Rizki Al-Fathir** — Backend & ML Engineer.
Built with [Next.js](https://nextjs.org/) 14, React 18, Tailwind CSS 3.

Design system: **RawBlock** — brutalist, black-on-white. Thick borders,
zero border radius, zero shadows, Archivo Black / Work Sans / Space Mono.
No polish on purpose.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint
